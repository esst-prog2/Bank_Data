# openspec/specs

Source of truth for *current, built* system behavior, organized by domain.
`data-retrieval/spec.md` is the live contract for `data_acquisition/reconcile.py`
and friends, landed 2026-10-11 when `add-mvp-v1` was implemented, verified, and
archived to `openspec/changes/archive/2026-10-11-add-mvp-v1/`.

A capability lands here once its change proposal under `openspec/changes/` is
implemented, verified, and archived (see that proposal's `tasks.md` and the
OpenSpec docs' archive process) - see `openspec/changes/archive/` for the full
history of changes that have shaped this spec.
